## ⚡ გაშვების ინსტრუქცია (Run Locally)

1. დააინსტალირეთ დამოკიდებულებები:
   ```bash
   npm install
   ```

2. გააშვით ლოკალური დეველოპმენტ სერვერი:
   ```bash
   npm run dev
   ```

3. პროექტის ბილდის შექმნა (Production Build):
   ```bash
   npm run build
   ```
